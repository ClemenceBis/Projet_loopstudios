
 Projet Loopstudios_Landingpage

Bienvenue dans le dépôt du projet Loopstudios_Landingpage. Ce fichier GUIDE vous expliquera comment contribuer au projet, organiser votre travail et soumettre vos modifications.

Objectif du projet

On doit reproduire le site Loopstudios landing page en utilisant html et css.

Organisation du travail

1. Cloner le dépôt

Commencez par cloner ce dépôt sur votre machine locale :

2. Créer une nouvelle branche

Avant de commencer à travailler, créez votre propre branche.

3. Travailler localement

Effectuez vos modifications localement dans votre branche.

4. Ajouter et valider les modifications

5. Pousser votre branche sur GitHub

6. Créer une Pull Request
Rendez-vous sur GitHub, créez une Pull Request (PR) depuis votre branche vers main. Ajoutez un message clair et attendez la relecture d’un membre du groupe.

Bonnes pratiques

- Travaillez toujours sur une branche séparée, jamais directement sur main.
- Faites des commits clairs et réguliers.
- Testez toujours votre code avant d’envoyer une PR.
- Commentez votre code si nécessaire pour aider les autres à comprendre.
- Respectez la structure du projet.
